# Getting started with Gist

Gist is a catalog and context library for AI clients. Public discovery is read-only and free to use without signing in. Start at https://gist.sire.run/library or use the REST API and public MCP endpoint described in https://gist.sire.run/developers.md.

## Discover, inspect, connect

Search by app name or use case. In an app listing, check whether connector_ids are available. Inspect the exact integration ID, read the transport and authentication setup, and export its descriptor if your client supports import. Then connect the provider in Zati or another compatible client. Gist does not connect your provider account when it returns a listing.

## Give the task a clear boundary

For an inbox briefing, choose the mailbox context and read tools in your client, define what a useful briefing contains and review the result. A workflow prompt on an app page is an idea to configure, not proof of an installed connection or a ready-made automation. The consuming client owns execution permissions and review.

## Private workspaces

Invited GitHub accounts can open private workspace content. Personal bookmarks appear first in signed-in catalog views. MCP access to private artifacts requires its own OAuth flow at https://gist.sire.run/mcp. Public discovery at https://gist.sire.run/directory/mcp does not require this enrollment.
