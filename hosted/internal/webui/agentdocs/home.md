# Gist AI integrations and skills

Gist by Sire Run, Inc. helps people and agents discover the right context, MCP servers and OpenAPI integrations for a task. Bring selected skills and setup metadata to Zati or another compatible client. Your client connects provider accounts and runs the work.

## Find a useful capability

Browse the public app library, search available connection descriptors, inspect the returned setup and export the exact descriptor you choose. An app listing describes discoverable software; available connector IDs identify its connection routes. Public discovery is free, read-only and requires no sign-in, credit card or API key.

- [App library](https://gist.sire.run/library)
- [MCP servers](https://gist.sire.run/library/mcp)
- [OpenAPI integrations](https://gist.sire.run/library/openapi)

## Connect an agent or application

Add https://gist.sire.run/directory/mcp as a Streamable HTTP server. It exposes gist_directory_search, gist_directory_get and gist_directory_export. Or call the public REST API: https://gist.sire.run/api/directory?q=calendar&limit=5. Neither interface executes provider tools.

- [Developer guide](https://gist.sire.run/developers.md)
- [OpenAPI description](https://gist.sire.run/openapi.json)
- [Agent instructions](https://gist.sire.run/llms.txt)
- [CLI and SDK](https://gist.sire.run/cli.md)

## Keep execution in your client

Your client selects tools, obtains provider authorization, enforces permissions and budgets, and reviews actions. Private workspace artifacts use invited GitHub sign-in and separate MCP OAuth authorization. They are not needed to browse public metadata.
