Gist — approved identity SVG pack

The selected page: reusable library cards bring the relevant item forward.

SVG assets live in hosted/internal/webui/assets/brand/.

FILES
gist-logo-*.svg       Horizontal symbol and wordmark
gist-symbol-*.svg     Standalone symbol
gist-wordmark-*.svg   Wordmark only
gist-app-icon-*.svg   Rounded square app icon

Green, ivory, black and white variants are supplied for transparent artwork.
App icons have an explicit background. All assets contain vector paths only:
no fonts, linked resources, embedded raster images, scripts or dependencies.

COLOR
Forest green #123D2C
Warm ivory   #F7F4EB

USAGE
Use green on ivory or light backgrounds; ivory or white on dark backgrounds.
Preserve aspect ratio. Keep clear space around the mark. SVGs scale freely.
For inline HTML with an adjacent text label, mark the SVG aria-hidden=true.
For an img element, supply appropriate alt text in the host document.
Check small icons at their actual display size before shipping.

PROVENANCE
Vector reconstruction traced from the approved generated identity artwork.
Antialiasing and raster texture were removed, with curves lightly simplified.
The tagline is intentionally separate from the reusable logo.
This export does not constitute trademark clearance.
