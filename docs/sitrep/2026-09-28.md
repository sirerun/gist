## Glossary for this report

- **RFC-002 / RFC-003**: the registry effort (discovery, retrieval,
  resolution — shipped) and the execution gateway effort (governed
  execution, credential custody, billing — building).
- **Gist**: the open-source product both efforts build.
- **foundation**: the private infrastructure repo where AWS deployment
  code and security documents live.
- **ADR**: an architecture decision record — a short document stating a
  decision, its context, and its consequences.
- **G0.x / G1.x**: task IDs in the gateway build plan; G0 is the review
  wave, G1 the first build wave.
- **M-G1**: the gateway's first milestone — core execution plus credential
  custody, gated on threat-model sign-off.
- **Q5**: the registry plan's deploy-and-verify milestone task.
- **build lease (R-build-lease)**: a shared lock so parallel sessions
  don't run heavy builds simultaneously on the Mac mini.
- **check.py / contract gate**: the script that freezes and verifies the
  public API contract; it must pass before any merge.
- **cloud agents**: the plan's build labor — Sonnet-class agents running in
  remote sandboxes, each opening a PR that is re-verified locally before
  merge.
