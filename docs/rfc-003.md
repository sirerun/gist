# RFC-003: Retired Gist execution-gateway proposal

- **Status:** Retired by owner decision, 2026-10-16; superseded by [ADR016](adr/016-zati-library-first-rfc003-gateway-boundary.md).
- **Disposition:** Catalog only; execution belongs to consuming runtimes or external providers. This is retirement, not conditional deferral.

Gist will not build or operate `gist_invoke`, a hosted execution endpoint,
provider-token custody, execution approvals or journals, or utility billing.
Zati, Foundry, Composio, or another explicitly selected executor owns those
operations and their credentials, permissions, cost enforcement and recovery.
Existing root-library local execution compatibility is not removed by this
architectural decision. No source change, deployment, credential migration or
service shutdown is authorized by this documentation change.

Catalog-side provider metadata, schemas, support evidence, complete skill
packages, guidance provenance, immutable identity and publisher verification
remain in [RFC-002](rfc-002.md). Registry authentication and publication signing
are distinct from provider credential custody and execution authorization.

The [pre-retirement proposal](plans/archive/20261016/rfc-003.md.source) preserves
its exact design and unresolved assumptions for historical reference only.
Neither its imperative language nor an old approval authorizes gateway work.
The canonical plan retains every original task ID and completion receipt;
uncompleted gateway obligations are retired and non-dispatchable, not completed.
